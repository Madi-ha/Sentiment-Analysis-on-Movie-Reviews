###Sentiment Analysis using Natural Language Processing (NLP)

## Overview
This project implements a complete **Natural Language Processing (NLP) sentiment classification pipeline** to predict whether a movie review expresses a **positive** or **negative** sentiment.

It demonstrates key NLP workflows including text preprocessing, feature extraction, supervised model training, and evaluation.

---

##  Objectives
- Build a sentiment classification model for textual movie reviews  
- Convert raw text into numerical features using TF-IDF  
- Train and compare multiple machine learning classifiers  
- Evaluate model performance on unseen review data  

---

##  Key Features
- Text preprocessing pipeline including:
  - Tokenization  
  - Stopword removal  
  - Lemmatization  
- Feature extraction using **TF-IDF Vectorization**  
- Trained ML models such as:
  - Logistic Regression  
  - Naive Bayes  
  - Support Vector Machine (SVM)  
- Sentiment prediction for new review inputs  

---

## Tech Stack
- Python  
- Scikit-learn  
- NLTK / SpaCy  
- Pandas, NumPy  
- Matplotlib
